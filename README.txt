**対応TvAIr：v1.2.14以上**  
**同梱Plugin SDK / Host Contract：1.1.18**

- その他軽微な修正。

## 製品説明

AIrConは、TvAIrで地上波・BS・CS・CATVの視聴操作を行うプラグインです。チャンネル選択、ザッピング、終了タイマー、視聴予約に対応します。

TvAIr番組表の「今すぐ視聴」からもTVTestを起動・選局できます。

## 主な機能

- 地上波・BS・CS・CATVのチャンネル選択
- 現在視聴中のチャンネル表示と局一覧の自動追従
- 一定間隔でチャンネルを切り替えるザッピング
- 指定時間後に視聴を終了するタイマー
- 番組を指定して自動で選局する視聴予約
- 長い番組タイトルのホバースクロール表示
- ライト・ダークテーマ対応
- ウィンドウ位置・サイズの保存

## 動作環境

- **TvAIr v1.2.14以上**
- 同梱Plugin SDK / Host Contract 1.1.18
- Windows / .NET 8
- x64 / x86
- Visual Studio 2022（ソースからビルドする場合）

TvAIr側で視聴用チューナーとTVTestを使用できる状態にしてください。CATVの視聴・視聴予約には、対応する視聴先と受信設定が必要です。

## インストール

1. ZIPを任意のフォルダに展開し、`AIrCon.sln`をVisual Studio 2022で開きます。
2. 構成`Release`、プラットフォーム`x64`または`x86`を選択し、ソリューションをビルドします。
3. TvAIrを終了し、生成された`AIrCon.BasicPlugin.dll`をTvAIrの`Plugins`フォルダ直下へ配置します。
4. TvAIrを起動し、Pluginメニューから`AIrCon`を開きます。

配置例：

```text
TvAIr/
├─ TvAIr.exe
└─ Plugins/
   └─ AIrCon.BasicPlugin.dll
```

AIrCon専用のサブフォルダは不要です。旧版から更新する場合は、TvAIrを終了した状態でDLLを置き換えてください。登録済みの設定や視聴予約を削除する必要はありません。

## 使用方法

### チャンネル選択

地上波・BS・CS・CATVのボタンで放送波を選び、局をダブルクリックするとTVTestで視聴します。CATVでは受信設定に登録された再送信局も選択できます。

放送波ボタンを押すと、対応するTVTestが起動済みの場合はそのウィンドウを前面に表示します。放送波ボタンだけではTVTestを新規起動したり、選局したりしません。

現在視聴中の局は局一覧の中央付近へ追従します。TvAIr番組表から選局した場合も同様です。AIrConが背面でも、ウィンドウが表示されていれば一覧が追従します。自動更新によってAIrConを勝手に前面へ移動しません。

### 番組タイトル表示

表示幅に収まらないタイトルへマウスを合わせると、横方向へスクロールして全文を確認できます。短いタイトルはスクロールしません。

### 視聴予約

局を右クリックすると、現在から約6時間先までの番組から視聴予約できます。番組開始30秒前に対象のチャンネルへ一度だけ自動で切り替えます。

AIrConを閉じても未実行の視聴予約は維持され、TvAIr再起動後も未来の予約は保持されます。視聴予約が実行されると、同じ視聴先のザッピングと終了タイマーは停止します。視聴予約は録画予約ではありません。

### ザッピング

開始すると設定間隔ごとに次のチャンネルへ切り替わります。選択中の視聴先ごとに動作し、複数の視聴先で別々に利用できます。AIrConを閉じると停止します。

### 終了タイマー

指定した時間が経過すると、対象のTVTestを終了します。視聴先ごとに設定でき、ザッピング中も使用できます。AIrConを閉じると解除されます。

## 更新方法

TvAIrを終了してから`AIrCon.BasicPlugin.dll`を置き換え、再起動後にAIrConが開くことを確認してください。

## 注意事項

CATVの局一覧表示にはTvAIr側の有効局情報が必要です。視聴・視聴予約にはCATV対応の視聴先と受信設定が必要です。利用可能な放送局は環境の設定によって異なります。
