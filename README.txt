## 製品説明

AIrConはTvAIr上で地上波・BS・CS・CATVの視聴操作を行うプラグインです。

チャンネル選択・ザッピング・終了タイマー・視聴予約に対応しています。TvAIrの視聴用チューナーを簡単に操作できます。

## 主な機能

- 地上波 / BS / CS / CATVのチャンネル選択
- 現在視聴中のチャンネル表示
- 一定間隔で次の局へ切り替えるザッピング
- 指定時間後に視聴を終了するタイマー
- 番組を指定して自動で選局する視聴予約
- 見切れた番組タイトルのホバースクロール表示
- ライト / ダークテーマ対応
- ウィンドウ位置・サイズの保存

## 動作環境

- TvAIr v1.2.14以上
- Windows
- .NET 8
- x64 / x86
- Visual Studio 2022（ソースからビルドする場合）

AIrConを利用するにはTvAIr側で視聴用チューナーが使用できる状態になっている必要があります。

放送波ボタンと局一覧はTvAIrの局情報に従って表示されます。

CATVの局一覧はCATV対応の視聴先が設定されていなくても閲覧できます。ただしCATVの視聴と視聴予約には対応する視聴先が必要です。

放送波ボタンを押すと局一覧が切り替わります。対応するTVTestが起動している場合はそのTVTestを前面に表示します。放送波ボタンだけではTVTestの新規起動や選局は行いません。

## 使用方法

### チャンネル選択

TvAIr番組表の「今すぐ視聴」からAIrCon経由でTVTestを起動・選局できます。

AIrConを開くと利用できる放送波のボタンとチャンネル一覧が表示されます。現在放送中の番組も確認できます。

地上波 / BS / CS / CATVのボタンで局一覧を切り替えます。

視聴したい局をダブルクリックすると対応する視聴先でチャンネルが切り替わります。

ザッピング中に局をダブルクリックした場合はザッピングを終了してから指定局へ切り替わります。

CATVの視聴先では受信設定に登録された地上波・BS・CSの再送信局も選択できます。

現在視聴中のチャンネルは局一覧の中央付近へ移動して表示されます。TvAIr番組表から選局した場合も同様です。

AIrConが背面にあってもウィンドウが表示されていれば選局先への移動を行います。この処理によってAIrConを前面に出したり他のウィンドウのフォーカスを変更したりすることはありません。

### 番組タイトル表示

番組タイトルが表示幅に収まらない場合はタイトルにマウスを合わせると少し待ってから横方向へスクロールします。

全文が表示されている短いタイトルはスクロールしません。

マウスを外すとタイトルは先頭位置へ戻ります。

### 視聴予約

局を右クリックするとその局の現在から約6時間先までの番組を表示できます。番組を選択して視聴予約を登録できます。

登録した視聴予約は番組開始30秒前になると対象のチャンネルへ一度だけ自動で切り替わります。

AIrConのウィンドウを閉じても登録済みの視聴予約は維持されます。TvAIrを再起動した場合も未実行の未来の視聴予約は維持されます。

視聴予約を実行するときは同じ視聴先で動作しているザッピングや終了タイマーを終了してからチャンネルを切り替えます。

視聴予約は録画予約ではありません。番組を録画したり番組終了まで視聴先を占有したりする機能ではありません。

### ザッピング

ザッピングを開始すると設定した間隔ごとに次のチャンネルへ自動で切り替わります。

ザッピングは選択中の視聴先に対して動作します。放送波ボタンで局一覧を切り替えただけでは終了しません。

ザッピングはAIrConのウィンドウを閉じると終了します。

### 終了タイマー

指定した時間が経過すると対象の視聴を自動で終了します。

終了タイマーはAIrConのウィンドウを閉じると解除されます。

## インストール

### 1. AIrConをビルドする

1. 配布ZIPを任意のフォルダへ展開します。
2. Visual Studio 2022と.NET 8 SDKを用意します。`AIrCon.sln`をVisual Studio 2022で開いてソースを確認できます。
3. 展開先の`build_release.cmd`を実行します。x64版とx86版が順番にビルドされます。
4. ビルドがエラー・警告ともに0件で完了したことを確認してください。

片方だけビルドする場合はコマンドプロンプトから次のいずれかを実行してください。

- x64版：`build_release.cmd x64`
- x86版：`build_release.cmd x86`

生成されるファイルは次のとおりです。

```text
AIrCon.BasicPlugin\bin\x64\Release\AIrCon.BasicPlugin.dll
AIrCon.BasicPlugin\bin\x86\Release\AIrCon.BasicPlugin.dll
```

使用するTvAIrのアーキテクチャに合わせてどちらか一方を配置してください。

### 2. TvAIrへ配置する

TvAIrを終了した状態で作業してください。

ビルドで生成された`AIrCon.BasicPlugin.dll`をTvAIrの`Plugins`フォルダ直下へ配置します。

```text
TvAIr/
├─ TvAIr.exe
└─ Plugins/
   └─ AIrCon.BasicPlugin.dll
```

`Plugins`フォルダ内にAIrCon専用のサブフォルダを作る必要はありません。

旧バージョンの`AIrCon.BasicPlugin.dll`がある場合は新しいDLLへ置き換えてください。

### 3. TvAIrを起動する

DLLを配置したあとTvAIrを起動します。

TvAIrのPluginメニューに`AIrCon`が表示されることを確認してください。

`AIrCon`を選択するとウィンドウが開きます。

### 4. 初回確認

AIrConを開いたら次の点を確認してください。

- 有効な局が存在する放送波のみ選択ボタンが表示される
- チャンネル一覧が表示される
- 現在視聴中のチャンネルが正しく表示される
- 局をダブルクリックすると視聴先が切り替わる

視聴予約を利用する場合は局を右クリックして番組一覧が表示されることも確認してください。

## 更新方法

旧バージョンから更新する場合はTvAIrを終了してから`AIrCon.BasicPlugin.dll`を新しいバージョンへ置き換えてください。

置き換え後にTvAIrを起動しPluginメニューからAIrConが正常に開くことを確認してください。

登録済みの設定や視聴予約を削除する必要はありません。

## 注意事項

CATVの局一覧表示にはTvAIr側の有効局情報が必要です。

CATVの視聴と視聴予約にはCATV対応の視聴先と受信設定が必要です。

利用できる放送局は環境の設定によって異なります。
