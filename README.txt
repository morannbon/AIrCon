# AIrCon v1.0.7

## v1.0.7 の更新内容

- CATV対応の視聴先が設定されていない場合でも、CATVタブから局一覧を確認できるようにしました。
- 放送波の切替と実際の選局を分離し、対応する視聴先がない場合は選局・視聴予約を行わないようにしました。

## 製品説明

AIrCon は、TvAIr 上で地上波・BS・CS・CATVの視聴操作を行うプラグインです。

チャンネル選択、ザッピング、終了タイマー、視聴予約に対応し、TvAIrの視聴用チューナーを簡単に操作できます。

## 主な機能

- 地上波 / BS / CS / CATV のチャンネル選択
- 現在視聴中のチャンネル表示
- 一定間隔で次の局へ切り替えるザッピング
- 指定時間後に視聴を終了するタイマー
- 番組を指定して自動で選局する視聴予約
- 見切れた番組タイトルのホバースクロール表示
- ライト / ダークテーマ対応
- ウィンドウ位置・サイズの保存

# 動作環境

- TvAIr v1.2.8 以上（全機能の対応条件。旧バージョンの動作保証なし）
- Windows
- .NET 8
- x64 / x86

AIrConを利用するには、TvAIr側で視聴用チューナーが使用できる状態になっている必要があります。CATVを利用する場合はCATV対応の視聴先を設定してください。放送波ボタンと局一覧はTvAIrの局情報に従って表示します。対応する視聴先がなくても局一覧を閲覧できます。放送波の切替だけではTVTestの起動・前面化・選局を行いません。実際の視聴や視聴予約には対応する視聴先が必要です。

# 使用方法

## チャンネル選択

AIrConを開くと、地上波・BS・CS・CATVのチャンネル一覧と現在放送中の番組が表示されます。

地上波 / BS / CS / CATV を切り替え、視聴したい局をダブルクリックすると対象の視聴先でチャンネルを切り替えられます。CATVの視聴先では、受信設定に存在する地上波・BS・CSの再送信局も選択できます。

現在視聴中のチャンネルは一覧上で確認できます。

## 番組タイトル表示

番組タイトルが表示幅に収まらない場合は、タイトルへマウスを合わせると少し待ってから横方向へスクロールします。

全文が表示できている短いタイトルはスクロールしません。

マウスを外すとタイトル表示は先頭位置へ戻ります。

## 視聴予約

局を右クリックすると、その局の現在から約6時間先までの番組を表示し、視聴予約を登録できます。

登録した視聴予約は、番組開始30秒前になると対象のチャンネルへ一度だけ自動で切り替わります。

AIrConのウィンドウを閉じても、登録済みの視聴予約は維持されます。

TvAIrを再起動した場合も、まだ実行されていない未来の視聴予約は維持されます。

視聴予約の実行時は、同じ視聴先で動作しているザッピングや終了タイマーを終了してからチャンネルを切り替えます。

視聴予約は録画予約ではありません。番組を録画したり、番組終了まで視聴先を占有したりする機能ではありません。

## ザッピング

ザッピングを開始すると、設定した間隔ごとに次のチャンネルへ自動で切り替わります。

ザッピングは選択中の視聴先に対して動作します。

ザッピングはAIrConのウィンドウを閉じると終了します。

## 終了タイマー

指定した時間が経過すると、対象の視聴を自動で終了します。

終了タイマーはAIrConのウィンドウを閉じると解除されます。

# インストール

## 1. AIrConをビルドする

1. 配布ZIPを任意のフォルダへ展開します。
2. `AIrCon.sln` を Visual Studio 2022 で開きます。
3. ビルド構成を `Release` にします。
4. 使用しているTvAIrに合わせて `x64` または `x86` を選択します。
5. ソリューションをビルドします。
6. エラーなくビルドが完了したことを確認します。

主な生成物は次のファイルです。

```text
AIrCon.BasicPlugin.dll
```

## 2. TvAIrへ配置する

TvAIrを終了した状態で作業してください。

ビルドして生成された

```text
AIrCon.BasicPlugin.dll
```

を、TvAIrの `Plugins` フォルダ直下へ配置します。

```text
TvAIr/
├─ TvAIr.exe
└─ Plugins/
   └─ AIrCon.BasicPlugin.dll
```

`Plugins` フォルダ内にAIrCon専用のサブフォルダを作る必要はありません。

既に旧バージョンの `AIrCon.BasicPlugin.dll` がある場合は、新しいDLLへ置き換えてください。

## 3. TvAIrを起動する

DLLを配置したあと、TvAIrを起動します。

TvAIrのPluginメニューに `AIrCon` が表示されることを確認してください。

`AIrCon` を選択すると、AIrConのウィンドウが開きます。

## 4. 初回確認

AIrConを開いたら、次の点を確認してください。

- 地上波 / BS / CS / CATV の放送波タブを選択できる（TvAIr側で提供される場合）
- チャンネル一覧が表示される
- 現在視聴中のチャンネルが正しく表示される
- 局をダブルクリックすると視聴先が切り替わる

視聴予約を利用する場合は、局を右クリックして番組一覧が表示されることも確認してください。

# 更新方法

旧バージョンから更新する場合は、TvAIrを終了してから `AIrCon.BasicPlugin.dll` を新しいバージョンへ置き換えてください。

置き換え後にTvAIrを起動し、PluginメニューからAIrConが正常に開くことを確認してください。

登録済みの設定や視聴予約を削除する必要はありません。
