# AIrCon v1.0.4

AIrCon は、TvAIr 上で地上波・BS・CS の視聴操作を行うプラグインです。

チャンネル選択、ザッピング、終了タイマー、視聴予約に対応します。

## 主な機能

- 地上波 / BS / CS のチャンネル選択
- 現在視聴中のチャンネル表示
- 一定間隔で次の局へ切り替えるザッピング
- 指定時間後に視聴を終了するタイマー
- 番組を指定して自動で選局する視聴予約
- ライト / ダークテーマ対応
- ウィンドウ位置・サイズの保存

## 視聴予約

局を右クリックすると、その局の現在から約6時間先までの番組を表示し、視聴予約を登録できます。

予約した番組は、開始前になると自動で対象のチャンネルへ切り替わります。

AIrCon のウィンドウを閉じても、登録済みの視聴予約は維持されます。

## ザッピング

ザッピングを開始すると、設定した間隔ごとに次のチャンネルへ自動で切り替わります。

地上波とBS/CSはそれぞれ独立して動作します。

## 終了タイマー

指定した時間が経過すると、対象の視聴を自動で終了します。

# インストール

## 1. AIrCon をビルドする

1. このZIPを任意のフォルダへ展開します。
2. `AIrCon.sln` を Visual Studio 2022 で開きます。
3. ビルド構成を `Release` にします。
4. 使用している TvAIr に合わせて `x64` または `x86` を選択します。
5. ソリューションをビルドします。
6. ビルドが正常終了したことを確認します。

主な生成物は次のファイルです。

`AIrCon.BasicPlugin.dll`

## 2. TvAIr へ配置する

TvAIr を終了した状態で作業してください。

ビルドして生成された

`AIrCon.BasicPlugin.dll`

を、TvAIr の

`Plugins`

フォルダ直下へ配置します。

例:

```text
TvAIr/
├─ TvAIr.exe
└─ Plugins/
   └─ AIrCon.BasicPlugin.dll
```

`Plugins` の中に `AIrCon` などの専用サブフォルダを作る必要はありません。

既に旧バージョンの `AIrCon.BasicPlugin.dll` がある場合は、新しいDLLへ置き換えてください。

## 3. TvAIr を起動する

DLLを配置したあと、TvAIr を起動します。

TvAIr の Plugin メニューに `AIrCon` が表示されることを確認してください。

`AIrCon` を選択すると、AIrCon のウィンドウが開きます。

## 4. 初回確認

AIrCon を開いたら、次の点を確認してください。

- 地上波 / BS / CS が切り替えられる
- チャンネル一覧が表示される
- 視聴中のチャンネルが正しく表示される
- チャンネルを選択すると視聴先が切り替わる

視聴予約を利用する場合は、局を右クリックすると番組一覧が表示されます。

## 更新時

旧バージョンから更新する場合は、TvAIr を終了してから `AIrCon.BasicPlugin.dll` を新しいバージョンへ置き換えてください。

置き換え後、TvAIr を起動して Plugin メニューから `AIrCon` が正常に開くことを確認してください。
