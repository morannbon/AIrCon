# AIrCon v1.0.3

※TvAIrバージョン1.2.0以上が必要です。

AIrConは、TvAIrからTVTestの視聴操作を行うためのプラグインです。

地デジ / BS / CS のチャンネル切り替え、ザッピング、終了タイマーなどの視聴操作を行えます。

## 主な機能

- 地デジ / BS / CS の視聴操作
- チャンネル切り替え
- 一定間隔で次の局へ切り替えるザッピング
- 終了タイマー
- 地デジとBS/CSの視聴チューナー選択
- ウィンドウ位置・サイズの保存
- TvAIrのライト / ダークテーマへの追従

## 動作について

視聴中のTVTestを切り替える場合は、可能な範囲で同じTVTestを維持したままチャンネルを変更します。

表示していない放送波でザッピングしている場合は、現在表示中の画面を不要に更新しません。

AIrConのウィンドウを閉じた場合や、TVTestをAIrConの電源OFF、TVTestの×ボタン、外部プロセス終了などで停止した場合は、AIrConの表示状態、ザッピング、終了タイマーも解除されます。

チューナー表示はTvAIrの視聴設定を使用し、地デジとBS/CSを個別に選択できます。

ウィンドウ位置・サイズの保存はユーザー設定に従います。

## 動作環境

- AIrCon 1.0.3
- TvAIr 1.2.0以上
- TvAIr Plugin SDK 1.1.5
- Visual Studio 2022
- Release x64 / Release x86

## Visual Studio 2022でビルドする

1. `AIrCon.sln` をVisual Studio 2022で開きます。
2. 構成を `Release` にします。
3. プラットフォームを `x64` または `x86` にします。
4. ソリューションをビルドします。
